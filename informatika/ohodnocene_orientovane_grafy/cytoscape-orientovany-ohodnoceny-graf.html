Orientovaný ohodnocený graf (Cytoscape.js)

Ukázka jednoduchého orientovaného, ohodnoceného grafu a jeho vykreslení pomocí Cytoscape.js.

Co je to graf?

Graf se skládá z vrcholů (uzlů) a hran. Pokud jsou hrany orientované, mají směr (např. A → B). Pokud jsou ohodnocené, každá hrana má hodnotu (např. cena, vzdálenost, platnost).

Jak to funguje v Cytoscape.js

  • nodes jsou objekty s data: { id: ... }.
  • edges jsou objekty s data: { source: ..., target: ..., weight: ... }.
  • Směrování zajistí curve-style a target-arrow-shape.

Příklad

Graf obsahuje 5 vrcholů a 6 orientovaných hran. Každá hrana nese ohodnocení (číslo).

cy.add({
  group: 'edges',
  data: { id: 'a_b', source: 'A', target: 'B', weight: 5 }
});
