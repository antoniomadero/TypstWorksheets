Orientovaný ohodnocený graf (Sigma.js)

Ukázka orientovaného ohodnoceného grafu vykresleného pomocí Sigma.js + Graphology.

Co je to graf?

Graf se skládá z vrcholů (uzlů) a hran. Orientovaný graf má hrany se směrem (např. A → B) a ohodnocený graf má hrany označené hodnotou (např. cena, vzdálenost, platnost).

Jak to funguje v Sigma.js

  • Graf data spravuje graphology (uzly, hrany, jejich atributy).
  • Sigma vykreslí graf v elementu <div> a může použít souřadnice x/y.
  • Směr hran se zobrazí pomocí šipek (type: 'arrow').

Příklad

Graf obsahuje 5 uzlů a 6 orientovaných hran s váhami.

const graph = new graphology.Graph();

graph.addNode('A', { label: 'A', x: 0, y: 0, size: 10 });
graph.addNode('B', { label: 'B', x: 1, y: 1, size: 10 });

graph.addEdgeWithKey('A_B', 'A', 'B', {
  label: '4',
  type: 'arrow',
  size: 1.5,
});

const renderer = new sigma.Sigma(graph, document.getElementById('sigma-container'));
