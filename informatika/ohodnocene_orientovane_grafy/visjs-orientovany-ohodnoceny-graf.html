Orientovaný ohodnocený graf (vis.js)

Ukázka jednoduchého orientovaného, ohodnoceného grafu a jeho vykreslení pomocí knihovny vis.js.

Co je to graf?

Graf je soubor vrcholů (uzlů) a hran. Orientovaný graf má hrany, které mají směr (např. A → B), a ohodnocený graf má hrany označené hodnotou (např. cena, vzdálenost, platnost).

Jak to funguje v vis.js

  • nodes jsou objekty s id a label.
  • edges jsou objekty s from, to a label pro ohodnocení.
  • Směřování se zobrazí pomocí arrows: 'to'.

Příklad

Graf obsahuje 5 uzlů a 6 orientovaných hran. Každá hrana má svoji váhu.

const nodes = new vis.DataSet([
  { id: 'A', label: 'A' },
  { id: 'B', label: 'B' },
  { id: 'C', label: 'C' },
  { id: 'D', label: 'D' },
  { id: 'E', label: 'E' },
]);

const edges = new vis.DataSet([
  { from: 'A', to: 'B', label: '4' },
  { from: 'A', to: 'C', label: '2' },
  { from: 'B', to: 'D', label: '5' },
  { from: 'C', to: 'D', label: '1' },
  { from: 'D', to: 'E', label: '3' },
  { from: 'C', to: 'B', label: '1' },
]);

Otevři tento soubor v prohlížeči (dvakrát klikni nebo Ctrl+O a vyber soubor).
